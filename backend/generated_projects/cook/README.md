# Cook Hospital Website
## Introduction
The Cook Hospital website is a modern web application designed to provide a user-friendly interface for patients and administrators. The website features a simple and intuitive design, making it easy for users to navigate and find the information they need.

## Features
* Modern design with a clean and minimalistic layout
* Admin panel for managing website content
* No authentication or payment integration

## Getting Started
To get started with the Cook Hospital website, simply open the `index.html` file in a web browser. The website is fully functional and does not require any additional setup or configuration.

## Folder Structure
The Cook Hospital website has the following folder structure:
* `public`: contains all public-facing files, including `index.html`, `styles`, `scripts`, and `images`
* `public/admin`: contains the admin panel files, including `index.html`
* `public/styles`: contains the website's stylesheet, `style.css`
* `public/scripts`: contains the website's script file, `script.js`
* `public/images`: contains the website's images, including `favicon.ico`
* `README.md`: contains information about the website and its features

## Technologies Used
* Frontend: HTML
* Styling: CSS
* Website Type: Hospital
* Theme: Modern
* Admin Panel: True
* Authentication: False
* Payment Integration: False
